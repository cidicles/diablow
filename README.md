# DIABLOW — Night of the Risen

A torchlit survivors-style horde slasher built with Phaser. Every sprite,
animation, tile and prop is AI-generated by the pipeline in `scripts/`:
keyframes from an image model, motion from a video model, then local stages
that key out a background colour the character doesn't use, un-mix the edges,
detect the loop length, and pack TexturePacker atlases with the pivot at the feet.

```
npm install
npm run studio            # local sprite studio (server.js)
npm run build:web         # static game build in web-build/
npm run gen-sprites       # the sprite pipeline
```

Provider credentials go in `.env` (never committed). See `scripts/PROVIDERS.md`.
Raw generation intermediates (`_work/`) are not in the repo; the finished sheets are.
